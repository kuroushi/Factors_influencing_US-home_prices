# 🏡 Analyzing Key Factors Influencing U.S. Home Prices (2000–2025)

This project aims to identify and quantify the key factors that have influenced residential home prices across the United States over the last two decades. Using a data science approach, we collected, cleaned, and analyzed historical data from multiple sources, including real estate listings, FRED data, interest rates, inflation indices, and employment statistics.

A machine learning model was developed to understand the relative importance of various factors in determining housing prices. Exploratory data analysis (EDA) revealed strong correlations between home prices and variables such as mortgage interest rates, gdp, unemployment rates etc.
